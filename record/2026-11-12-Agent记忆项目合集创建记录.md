# 2026-11-12 Agent 记忆项目合集创建记录

目标仓库：<https://github.com/ZanePoe/awesome_agent_memory>

根据三份既有调研创建 Agent 记忆项目合集，首版收录 87 个 canonical GitHub 仓库，其中 54 个来自原报告与 Honcho 专项，33 个为本轮补充。分类覆盖记忆引擎、文件真源、图谱时序、编码 Agent/MCP、程序性记忆、研究评测、相邻基础设施以及历史/受限许可。

通过三轮深度检索登记 847 个来源；使用内容工厂最近三个月数据得到 72 个不同来源，补出 Hy-Memory、MemT、BEMULA 等近期方向。一组内容工厂查询连续两次 HTTP 503，未误记为零结果，随后替代查询成功。

用户报告中的 51 个 GitHub 基线 URL 覆盖率 100%。外部 awesome 索引覆盖率 85.6%，剩余多为商业网站、徽章、许可证链接和非项目术语。

项目表保存固定提交证据和许可证边界；README、详表、四种排序和 CSV 从 JSON 确定性生成。每日 GitHub Actions 只刷新 star、默认分支提交、新鲜度、归档和 release，不自动修改人工功能判断。

本轮未做统一运行测评，维护分不是记忆准确率或安全性排名。完整方法见 [检索记录](../docs/research.md)。
